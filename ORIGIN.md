# Provenance

Aitvaras is developed as an open-source project. Architecture decisions, protocol changes and implementation evidence are maintained in this repository.

## Clean-room rule

The implementation must be independently designed. Private repositories, internal tickets or documents, customer configurations, credentials, proprietary source code and incompatibly licensed material must not be copied or paraphrased into the project.

Reusable third-party code requires a compatible license and recorded provenance. Secrets, private keys, key shares and production credentials must never be committed.
